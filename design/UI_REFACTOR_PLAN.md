# 《AI 健身助手 UI 重构实施方案》

> 基于 `design/ui-reference.png` 视觉参考，对 `E:\Sport` 微信小程序进行纯 UI/UX 视觉重构。  
> 本方案只涉及 **WXML / WXSS / 静态图片 / 纯展示组件**，不修改业务逻辑、services、cloudfunctions、数据库、AI Agent。

## 三、Design Token 方案

### 3.1 策略

**不新建 `design/design-tokens.wxss`**，而是直接增强已有的 `app.wxss`（它已是全站 token 单一来源，被所有页面隐式继承）。原因：

- 现有 token 体系已生效，新建文件会造成双份来源和迁移风险。
- 在现有变量基础上**增补/校准**即可，保持向后兼容。

### 3.2 变更内容（app.wxss）

**校准/新增变量：**

```css
--cat-bg: #F7F8FA;                  /* 校准背景为浅灰白 */
--cat-orange: #FFB54D;              /* 主橙（与参考图一致） */
--cat-orange-deep: #FF9F1C;
--cat-orange-soft: #FFF3D6;
--cat-success: #66CDAA;             /* 健康绿 */
--cat-success-deep: #3FAE85;
--cat-success-soft: #EAFBF4;
--cat-blue: #4D9EFF;
--cat-blue-soft: #E8F7FF;
```

**新增全局原语类：**

- `.btn-orange`：橙色主按钮（训练/开始训练专用），渐变 `#FFC566 → #FFB54D → #FF9F1C`，白字胶囊，橙色阴影。
- `.page-header`：页面标题区（左标题 + 右猫咪/装饰）。
- `.cat-thumb`：动作卡片右侧猫咪缩略图容器（统一 120rpx，可选动画）。
- `.icon-btn-del`：红色垃圾桶/删除小图标按钮（饮水记录删除）。
- `.bubble-avatar`：AI 气泡猫咪头像。
- `.done-banner` 增强：胜利猫 + "坚持就是胜利！" 文案。

**注意**：保留现有 `.btn-primary`（绿色，用于"喝一杯"/"保存"等正向健康操作），不强行改橙，避免语义混乱。

## 四、公共组件方案

遵循"不过度组件化，只抽真正复用的 UI"原则。

### 4.1 增强/统一现有组件

**`components/cat-illustration/`（统一为全站猫咪组件）**

- 扩展 `pose` 属性：`home / workout / water / success / ai / empty / wave / coach / stats / weight`。
- 新增 `animate` 支持 `float`（上下浮动，用于页头装饰）、`bounce`（轻弹，用于完成庆祝）。
- 统一尺寸比例、透明背景、任意缩放。
- 在首页等已使用 `cat-mascot` 的地方，替换为 `cat-illustration`，保持角色统一。

**`components/float-ball/`（增强，不新增）**

- 将 🐈 emoji 替换为 `cat-illustration` 的 `coach` 姿态（或 `home` 姿态），保持圆形头像样式。
- **保留全部交互**：拖拽、jumping 蹦跳动画、位置记忆（left/top）、点击进 AI。
- 改动仅限 WXML/WXSS 呈现层，JS 逻辑不动。

### 4.2 新增组件

**`components/section-title/`（区块标题）**

- 结构：猫爪/图标小标 + 标题文字 + 可选右侧链接。
- 复用位置：各页面卡片标题（今日训练、今日饮水、本周概览、身体数据、体重趋势等）。
- 属性：`title`、`icon`（默认 🐾）、`link`、`bind:linktap`。

> 不新增 card/pill/progress/empty-state 组件——这些已由 `app.wxss` 全局类覆盖。

## 六、页面改造顺序与具体内容

严格按 Phase 顺序，每页只改 WXML/WXSS/JSON，不动 JS 业务逻辑。

### Phase 4：公共组件
